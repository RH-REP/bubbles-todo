# Bubbles

思いついたことを書き出して、漂わせておくための todo アプリ（試作）。

**[動かしてみる →](https://rh-rep.github.io/bubbles-todo/)**

---

## このアプリが引き受けないこと

普通の todo アプリは、開くと「やっていないことの山」を返してくる。
これはその形を採らない。**未処理の山を、罰として突き返さない。**

そのために、次のものを**作らない**と決めてある。

- 達成率・パーセント・分母のある数字
- 連続日数（ストリーク）
- 完了したときのご褒美演出
- 「やる気」ゲージのようなもの
- やらなかった日を赤くすること
- 命令形の文言（「〜しなさい」「〜しましょう」）

記録するのは **「はじめた」** だけ。**「終わったか」は訊かない。**
「作業メモ → 次の一手」は git のように積み上がるが、**積むのは押したときだけ**
（打っている途中では記録しない）。
完了は、訊かれて答えるものではなく、**自分から押したいときに押すもの**として置いてある。

「消す」は本当に消しているように見えるが、内部では墓石として残る
（表示からは完全に消えるが、記録としては残り続ける）。

## 6つの画面

| | |
|---|---|
| **海** | 思いつきを吐き出す場所。バブルが漂う。**上=長期保留 / 下=完了**（動かせない固有枠）、左右はタグの海 |

長期保留には**もどってくる日**を添えられる。その日が来ると、ほかの海へ静かに戻る
（「期限切れ」も「◯日放置」も出さない。過ぎた日は、開いた時点で戻すだけ）。
| **今日** | 今日やると決めたもの |
| **きっかけ** | 「歯を磨いたら」のような、行動のきっかけにぶら下げるもの |
| **すきま** | 耳だけ空いている／画面が見られる、といった状況ごとの枠。1枠1つ |
| **ふりかえり** | 完了ではなく**着手**の記録。帯グラフは置いていない（比率の絵になるため） |
| **設定** | タグの管理、音のオン/オフ |

バブルはタブへ直接ドラッグできる。落としても**移動ではなく、状態が増える**
（今日にもあるし、きっかけにもある、という持ち方ができる）。

## 触り方

- **タップ** … バブルが中央に来る。次の一手・リンク・履歴・タグの付け外しが出る
- **バブルの [OK]** … 「作業メモ → 次の一手」を1組にして、git のように記録を積む。
  打っている途中では記録しない（積むのは OK を押したときだけ）
- **バブルの [履歴]** … 積んだ記録を日時つきで古い順に読む
- **中央の [まずは開始]** … 5分の集中画面へ。そこでも同じ組を積める
- **タブへドラッグ** … その状態を足す
- **海の端へドラッグ** … そのタグが付く
- **矢印看板を押す／背景をなぞる** … となりの海へ
- **引いて見る** … バブルを小さくして、一度に多く見る

## 作り

- **素の ES モジュール。ビルド工程なし。外部依存ゼロ**（CDN もパッケージも使っていない）
- 保存は `localStorage` のみ。**通信は一切しない**（`fetch` も `XHR` もコードに存在しない）
- 物理（漂う・投げる・跳ね返る・引力のあるセル）は `js/drift.js` の自前実装
- 完了音は音声ファイルを持たず WebAudio で合成する
- 色は OKLCH で設計し、色覚特性下の色差とコントラストを実測して決めている

```
index.html
css/          骨格・バブル・集中画面・画面ごとのスタイル
js/
  app.js      起動と画面の切り替え
  store.js    データ層（唯一の状態の持ち主）
  drift.js    物理
  bubble.js   バブルの DOM とジェスチャ、中央の盤
  focus.js    5分の集中画面
  sound.js    完了音
  screens/    6つの画面
tests/        store.js のテスト（素の Node と assert だけ）
```

### 動かす

ES モジュールを使うので `file://` では動かない。サーバが要る。

```bash
python3 serve.py
```

`http://localhost:8931/` が開く（このサーバは開発補助で、アプリ本体には含まれない。
ES モジュールが強くキャッシュされるので `Cache-Control: no-store` を返している）。

### テスト

```bash
node tests/store.test.mjs
```

## いまの状態

試作です。**まだ実機で触っていません**（検証はすべて合成イベント）。
決まっていないこと・確かめられていないこと・根拠の弱い決定は
[`DEV_NOTES.md`](DEV_NOTES.md) にすべて書き出してあります。

とくに次の3つは実機でしか分かりません。

1. **描画の重さ** — バブル1つに7層のグラデーションが乗り、`backdrop-filter` も使っている
2. **ソフトキーボード** — Android はキーボードでビューポート自体が縮む
3. **実機タッチ全般**

また、**Android の戻るボタンには未対応**です（`history` を使っていないので、
戻るとアプリごと終了する）。
